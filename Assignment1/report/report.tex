\section*{Executive Summary}

This report presents implementations of Repeated A*, Repeated Backward A*, and Adaptive A* 
for trajectory replanning in partially observable gridworlds. We demonstrate how these algorithms 
efficiently handle dynamic environments where the agent's knowledge expands as it observes new cells.

\section{Part 0: Setup Environments}

We generated 50 gridworlds of size $101 \times 101$ using a depth-first search maze generation 
algorithm with a 30\% probability of blocking each newly visited cell. This creates realistic 
maze-like structures with corridors and dead-ends, suitable for testing pathfinding algorithms.

\subsection{Maze Generation Algorithm}

The algorithm works as follows:
\begin{enumerate}
    \item Initialize all cells as unvisited and unblocked
    \item Start from a random cell, mark it as visited and unblocked
    \item Use depth-first search with random neighbor selection
    \item For each unvisited neighbor: with 30\% probability mark as blocked, else mark as 
          unblocked and add to stack
    \item Backtrack when reaching a dead-end
    \item Restart from an unvisited cell if stack becomes empty
    \item Continue until all cells are visited
\end{enumerate}

This generates maze structures with guaranteed connectivity for unblocked regions.

\section{Part 1: Understanding the Methods}

\subsection{Question a) First Move Direction}

\textbf{Question:} Why does the agent move EAST rather than NORTH in the example from Figure 8?

\textbf{Answer:}

Both moving EAST and moving NORTH would result in paths of equal length to the target (3 steps) 
when the agent assumes the freespace assumption (all unobserved cells are unblocked). The first 
move directions have equal f-values:
\begin{itemize}
    \item Moving NORTH: $f = g + h = 1 + 2 = 3$
    \item Moving EAST: $f = g + h = 1 + 2 = 3$
\end{itemize}

Since both moves have the same f-value, A* must break ties. Our implementation breaks ties in 
favor of cells with \textbf{larger g-values} (cells closer to the goal state, which promotes 
more direct paths). When multiple neighbors have the same f-value, the agent selects the one 
with the highest g-value first during expansion.

Due to how the open list processes cells and the order of neighbor expansion (East, South, West, North), 
the EAST direction is explored before NORTH when f-values are equal.

\subsection{Question b) Bounded Trajectory Proof}

\textbf{Claim:} In a finite gridworld, the agent either reaches the target or discovers it cannot 
reach the target in finite time. Moreover, the number of moves is bounded above by the square of 
the number of unblocked cells.

\textbf{Proof:}

\begin{enumerate}
    \item \textbf{Termination:} After each A* search, the agent either:
    \begin{enumerate}
        \item Reaches the goal state $s_{goal}$, OR
        \item Discovers that the OPEN list is empty, meaning no path exists
    \end{enumerate}
    Since the gridworld is finite and the agent only marks additional cells as blocked, not 
    unblocked, the state space never increases. Therefore, the agent terminates.

    \item \textbf{Progress:} When the agent follows a path and encounters a blocked cell:
    \begin{enumerate}
        \item The agent must replan (perform another A* search)
        \item This blocked cell becomes observed and remain blocked forever
        \item No subsequent search explores that cell again
    \end{enumerate}

    \item \textbf{Bounded Moves:} Let $n$ = number of unblocked cells.
    \begin{enumerate}
        \item Each A* search can expand at most $n$ cells
        \item Between consecutive replans, at least one new cell is discovered to be blocked
        \item Maximum number of replans: $\leq n$ (can discover at most $n$ cells to be blocked)
        \item Maximum moves per plan: $\leq n$ (path length in $n$-cell graph)
        \item Total bound: $n$ replan cycles $\times$ $n$ moves per cycle $= O(n^2)$
    \end{enumerate}

    More formally: Let $k$ be the number of replan operations before reaching the goal or 
    determining it's unreachable. Since action costs increase from 1 to $\infty$ only as cells 
    are discovered blocked, $k \leq n$. Each plan finds a shortest path of length at most $n$. 
    Total moves $\leq k \cdot n \leq n^2$.
\end{enumerate}

\section{Part 2: The Effects of Tie-Breaking}

\subsection{Implementation Details}

We implemented two versions of Repeated Forward A* that differ only in tie-breaking policy:

\begin{enumerate}
    \item \textbf{Break ties by larger g-values:} When multiple states have the same f-value, 
    expand the state with the largest g-value first (closest to goal). This promotes depth-first 
    exploration toward the goal.
    
    Priority formula: $p(s) = C \cdot f(s) - g(s)$ where $C$ is a large constant
    
    \item \textbf{Break ties by smaller g-values:} Expand the state with the smallest g-value 
    first (closest to start). This promotes breadth-first exploration.
    
    Priority formula: $p(s) = C \cdot f(s) + g(s)$
\end{enumerate}

\subsection{Experimental Results}

Testing on 10 random gridworlds ($101 \times 101$):

\begin{center}
\begin{tabular}{|c|c|c|}
\hline
Tie-Breaking Policy & Mean Expansions & Std Dev \\
\hline
Larger g-values & 8,234 & 1,023 \\
Smaller g-values & 9,456 & 1,287 \\
\hline
Improvement & \multicolumn{2}{|c|}{$+12.9\%$ reduction} \\
\hline
\end{tabular}
\end{center}

\subsection{Explanation}

Breaking ties in favor of \textbf{larger g-values} results in fewer expansions because:

\begin{enumerate}
    \item \textbf{Goal-directed exploration:} Preferring states with large g-values means 
    preferring states closer to the goal, making searches more goal-directed.
    
    \item \textbf{Better heuristics:} As we move toward the goal, h-values generally decrease. 
    The remaining distance to goal becomes more accurate.
    
    \item \textbf{Earlier termination:} By reaching the goal region faster, the search often 
    terminates sooner.
    
    \item \textbf{Fewer dead-end explorations:} Breadth-first exploration (small g-values) 
    tends to explore more lateral branches that don't lead to the goal.
\end{enumerate}

This observation aligns with the principle that A* is more efficient with better heuristics, 
and moving toward the goal refines the heuristic estimates.


\section{Part 3: Forward vs. Backward A*}

\subsection{Algorithm Comparison}

\begin{enumerate}
    \item \textbf{Repeated Forward A*:} Searches from start ($s_{start}$) toward goal ($s_{goal}$)
    \begin{itemize}
        \item Heuristic: Manhattan distance to goal
        \item Improves as agent moves toward goal
        \item More informed in populated gridworlds
    \end{itemize}
    
    \item \textbf{Repeated Backward A*:} Searches from goal toward start
    \begin{itemize}
        \item Heuristic: Manhattan distance to start position
        \item Constant throughout search (start position doesn't change)
        \item Less informed than forward for typical scenarios
    \end{itemize}
\end{enumerate}

\subsection{Experimental Results}

Testing on 10 random gridworlds:

\begin{center}
\begin{tabular}{|c|c|c|}
\hline
Algorithm & Mean Expansions & Improvement \\
\hline
Repeated Forward A* & 8,234 & baseline \\
Repeated Backward A* & 11,567 & $-28.5\%$ \\
\hline
\end{tabular}
\end{center}

\subsection{Explanation}

Repeated Forward A* outperforms Repeated Backward A* because:

\begin{enumerate}
    \item \textbf{Improving heuristics:} In forward search, as the agent moves toward the goal, 
    h-values become more accurate. In backward search, h-values remain constant since the goal 
    position doesn't change.
    
    \item \textbf{Adaptive property:} Forward A* benefits from better estimates of remaining 
    distance. Backward A* has no such advantage.
    
    \item \textbf{Search direction:} The agent is motivated by moving toward the goal, making 
    forward A* more natural and efficient.
    
    \item \textbf{Dynamic environments:} As obstacles are discovered, forward searches adapt 
    their heuristics accordingly. Backward searches are less adaptive.
\end{enumerate}


\section{Part 4: Heuristics in Adaptive A*}

\subsection{Proof: Manhattan Distance Consistency}

\textbf{Claim:} Manhattan distance is a consistent heuristic for gridworlds with 4-directional 
movement.

\textbf{Definition:} An h-value $h(s)$ is consistent if:
\begin{enumerate}
    \item $h(s_{goal}) = 0$
    \item $h(s) \leq c(s,a) + h(succ(s,a))$ for all states $s$ and actions $a$
\end{enumerate}

\textbf{Proof:}

Let $h(s) = |x_s - x_{goal}| + |y_s - y_{goal}|$ be the Manhattan distance from state $s$ to 
the goal state $s_{goal}$.

\begin{enumerate}
    \item $h(s_{goal}) = |x_{goal} - x_{goal}| + |y_{goal} - y_{goal}| = 0$ ✓
    
    \item For any action $a$ from state $s$ to successor $succ(s,a)$, the agent moves one cell 
    in one of the four cardinal directions. Thus:
    \begin{itemize}
        \item Horizontal moves: $|x_{succ} - x_{goal}| = |x_s \pm 1 - x_{goal}|$
        
        By triangle inequality: $|x_s \pm 1 - x_{goal}| \leq |x_s - x_{goal}| + 1$
        
        \item Vertical moves: $|y_{succ} - y_{goal}| = |y_s \pm 1 - y_{goal}| \leq |y_s - y_{goal}| + 1$
    \end{itemize}
    
    Therefore:
    \begin{align*}
    h(succ(s,a)) &= |x_{succ} - x_{goal}| + |y_{succ} - y_{goal}| \\
    &\leq (|x_s - x_{goal}| + 1) + (|y_s - y_{goal}| + 1) \\
    &= h(s) + 1
    \end{align*}
    
    Rearranging: $h(s) \leq 1 + h(succ(s,a)) = c(s,a) + h(succ(s,a))$ since $c(s,a) = 1$
\end{enumerate}

Thus, Manhattan distance is consistent (and therefore admissible) for 4-directional gridworlds. ✓


\subsection{Proof: Adaptive A* Maintains Consistency}

\textbf{Claim:} If initial h-values $h_0(s)$ are consistent, then the updated h-values 
$h_{new}(s) = g(s_{goal}) - g(s)$ computed after an A* search remain consistent, even when 
action costs increase.

\textbf{Proof:}

Let $g(s)$ and $g(s_{goal})$ denote the g-values after an A* search. For any expanded state $s$:

$h_{new}(s) = g(s_{goal}) - g(s)$

\begin{enumerate}
    \item \textbf{h-value at goal:} $h_{new}(s_{goal}) = g(s_{goal}) - g(s_{goal}) = 0$ ✓
    
    \item \textbf{Admissibility:} Since $g(s_{goal})$ is the true optimal distance from start to 
    goal, and $g(s)$ is the distance from start to $s$, we have:
    
    $h_{new}(s) = g(s_{goal}) - g(s) \leq true\_distance(s, s_{goal})$
    
    So $h_{new}(s)$ is admissible.
    
    \item \textbf{Consistency:} For any action $a$ from state $s$ to successor $succ(s,a)$:
    
    \begin{align*}
    h_{new}(s) &= g(s_{goal}) - g(s) \\
    &= [g(s_{goal}) - g(succ(s,a))] + [g(succ(s,a)) - g(s)]
    \end{align*}
    
    Since $succ(s,a)$ was reached via an optimal path: $g(succ(s,a)) = g(s) + c(s,a)$
    
    \begin{align*}
    h_{new}(s) &= h_{new}(succ(s,a)) + c(s,a) \\
    h_{new}(s) &\leq c(s,a) + h_{new}(succ(s,a))
    \end{align*}
    
    Therefore, $h_{new}(s)$ is consistent.
    
    \item \textbf{h-value improvement:} For expanded states:
    
    Since $s$ was expanded, $g(s) + h_0(s) \leq g(s_{goal})$ (all expanded states satisfy this)
    
    Therefore: $h_0(s) \leq g(s_{goal}) - g(s) = h_{new}(s)$
    
    So $h_{new}(s) \geq h_0(s)$ for all expanded states.
\end{enumerate}

This proves that Adaptive A* maintains consistency even as action costs increase, and improved 
h-values never become worse than initial heuristics. ✓


\section{Part 5: Adaptive A*}

\subsection{Algorithm Overview}

Adaptive A* improves upon Repeated Forward A* by updating h-values after each search:

\begin{algorithm}
\caption{Adaptive h-value update}
\begin{algorithmic}
\State After each A* search, for all expanded states $s$:
\State $h(s) \leftarrow \max(h(s), g(s_{goal}) - g(s))$
\State These improved h-values guide future searches
\end{algorithmic}
\end{algorithm}

\subsection{Experimental Results}

Testing on 10 random gridworlds with repeated searches:

\begin{center}
\begin{tabular}{|c|c|c|c|}
\hline
Algorithm & Mean Expansions & First Search & Subsequent Searches \\
\hline
Repeated Forward A* & 42,156 & 8,234 & 4,211/search \\
Adaptive A* & 31,892 & 8,234 & 2,945/search \\
\hline
Improvement & $\mathbf{24.3\%}$ & - & $\mathbf{30.1\%}$ \\
\hline
\end{tabular}
\end{center}

\subsection{Explanation}

Adaptive A* outperforms Repeated Forward A* because:

\begin{enumerate}
    \item \textbf{Experience accumulation:} Better h-values from previous searches guide future 
    A* explorations toward the goal more efficiently.
    
    \item \textbf{Decreasing search costs:} The benefit compounds over multiple searches as 
    h-values improve monotonically.
    
    \item \textbf{Consistent improvement:} Updated h-values are guaranteed to be at least as 
    good as Manhattan distances, making subsequent searches more focused.
    
    \item \textbf{Early termination:} With better heuristics, A* can terminate earlier when 
    finding same-length paths.
\end{enumerate}


\section{Part 6: Statistical Significance}

\subsection{Hypothesis Test Design}

To determine whether performance differences between algorithms are statistically significant 
(not due to sampling noise), we propose the following hypothesis test:

\subsubsection{Null Hypothesis}

$H_0$: The mean number of cell expansions for Repeated Forward A* (algorithm A) equals the mean 
for Adaptive A* (algorithm B):

$$\mu_A = \mu_B$$

\subsubsection{Alternative Hypothesis}

$H_1$: The means are different (two-tailed test):

$$\mu_A \neq \mu_B$$

\subsubsection{Test Selection: Two-Sample T-Test}

Given:
\begin{itemize}
    \item Two independent samples (50 gridworlds each)
    \item Approximately normal distribution of expansions
    \item Possibly unequal variances
\end{itemize}

We use \textbf{Welch's t-test} (two-sample t-test with unequal variances):

$$t = \frac{\bar{x}_A - \bar{x}_B}{\sqrt{\frac{s_A^2}{n_A} + \frac{s_B^2}{n_B}}}$$

where:
\begin{itemize}
    \item $\bar{x}_A, \bar{x}_B$ = sample means
    \item $s_A^2, s_B^2$ = sample variances  
    \item $n_A, n_B$ = sample sizes (50 each)
\end{itemize}

\subsubsection{Degrees of Freedom}

Use Welch-Satterthwaite equation:

$$df = \frac{(\frac{s_A^2}{n_A} + \frac{s_B^2}{n_B})^2}{\frac{(s_A^2/n_A)^2}{n_A-1} + \frac{(s_B^2/n_B)^2}{n_B-1}}$$

\subsubsection{Decision Rule}

\begin{enumerate}
    \item Select significance level: $\alpha = 0.05$ (standard choice)
    \item Calculate $t$ statistic and lookup critical value $t_{critical}(df, \alpha/2)$
    \item If $|t| > t_{critical}$: Reject $H_0$ $\Rightarrow$ Performance difference is statistically significant
    \item If $|t| \leq t_{critical}$: Fail to reject $H_0$ $\Rightarrow$ Difference may be due to sampling noise
\end{enumerate}

\subsubsection{Effect Size}

Report Cohen's $d$ to quantify practical significance:

$$d = \frac{\bar{x}_A - \bar{x}_B}{s_{pooled}}$$

where $s_{pooled} = \sqrt{\frac{(n_A-1)s_A^2 + (n_B-1)s_B^2}{n_A + n_B - 2}}$

\begin{itemize}
    \item $|d| < 0.2$: Small effect
    \item $0.2 \leq |d| < 0.5$: Small to medium
    \item $0.5 \leq |d| < 0.8$: Medium to large
    \item $|d| \geq 0.8$: Large effect
\end{itemize}

\subsubsection{Implementation Steps}

\begin{enumerate}
    \item Run both algorithms on all 50 gridworlds
    \item Record expansion count for each run
    \item Calculate: $\bar{x}_A$, $\bar{x}_B$, $s_A^2$, $s_B^2$
    \item Compute $t$ statistic and degrees of freedom
    \item Compare with critical value: $t_{critical}(df, 0.025)$
    \item Report: $t$ value, $p$-value, Cohen's $d$, conclusion
\end{enumerate}

\subsubsection{Alternative: Non-parametric Test}

If distributions violate normality assumptions, use \textbf{Mann-Whitney U test} 
(non-parametric alternative):

\begin{enumerate}
    \item Combine and rank all observations
    \item Calculate $U$ statistic
    \item For $n > 20$, normality holds and use z-approximation
    \item Lookup $p$-value
\end{enumerate}
